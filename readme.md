Unmanned aerial vehicle (UAV)-based visual monitoring is critical for real-time fire detection in complex environments like mountainous photovoltaic power stations. However, two challenges remain: (1) feature aliasing, where specular reflections exhibit patterns highly similar to incipient flames; and (2) gradient degradation, where weak smoke edge features are eroded by aggressive downsampling. To address these, this paper proposes GPA-FireNet (Gradient Prior and Axial attention optimized Fire detection Network), a lightweight network synergizing physical priors with attention mechanisms. An Efficient Linear Dual-Axial Attention (ELDA) module captures global dependencies via orthogonal axial decomposition, suppressing reflective interference while enhancing fire responses. A Gradient Prior Enhancement Module (GPEM) embeds the Scharr operator as a zero-parameter prior, compensating for edge information loss during feature fusion. A dedicated dataset incorporating hard negative samples with intense specular reflections is also constructed. Experimental results demonstrate that GPA-FireNet achieves 88.1\% $\mathrm{mAP_{0.5}}$ and 68.2\% $\mathrm{mAP_{0.5:0.95}}$ on the proposed dataset, outperforming the baseline by 2.7\% and 4.1\%, respectively. On the public M$^4$SFWD benchmark, it attains state-of-the-art 88.5\% $\mathrm{mAP_{0.5}}$. Deployment on Raspberry Pi 5 validates real-time inference capability for edge-based UAV visual inspection systems.
